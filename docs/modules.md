# 功能模块与验收状态

范围以原始项目计划及本轮确认的 GUI、网页登录引导、95% 提醒、后台更新与回滚、EXE/DMG 发行为准。以下区分代码实现与真实账号验收，避免用版本号替代验证。

| 模块 | 当前实现 | 验证边界 |
| --- | --- | --- |
| 账号管理 | 添加、重命名、移除登记、默认选择、稳定 ID、独立官方目录；移除保留官方数据 | 两个真实账号重启后身份隔离需用户验收 |
| 官方登录与启动 | 创建后默认调用官方登录、系统终端、直接 argv、工作目录和原参数传递 | 浏览器登录由官方客户端完成；不代理 OAuth |
| 项目绑定与并发 | 显式选择优先、精确目录绑定、默认及选择菜单；受管账号/项目锁 | 不能约束工具外启动的 Claude 或编辑器 |
| 身份与诊断 | 明确查询官方身份、版本适配、未知状态、认证/供应商/环境冲突预检 | 不伪装成企业策略的完整合并器；真实身份以官方 /status 为准 |
| 官方额度 | 文档支持的 statusline、5h/7d、90% 交接提醒、任一窗口 95% 手动切换建议、过期/未知 | 最近上报快照，不后台登录所有账号查询；95% 不保证任务余量 |
| 手动记录 | 分别记录窗口百分比/重置和本地限额截止；来源/时间/到期、查看和清除 | 与官方观察分开；没有自动轮换或自动阻断 |
| 工作交接 | 模板、编辑、保存冲突检测、审阅确认、新账号新会话读取项目状态 | 不共享或复制历史，不承诺跨账号恢复同一 transcript |
| 便携导入导出 | 账号名称、标签、默认；合并保留已有身份 | 无凭据、ID、路径和历史，另一设备重新登录 |
| 本地备份恢复 | 稳定 ID、默认与项目绑定；预览摘要确认、恢复前备份、损坏原文件保留、活动会话保护 | 同一数据目录恢复；不覆盖凭据/历史，不等于项目文件备份 |
| 版本与配置兼容 | schema v1 直接读取 alpha.1 数据；未知 schema 拒绝写入；升级前元数据备份 | 尚无第二种注册表 schema，无需人为制造迁移；将来改变时需配套恢复 |
| 桌面工作台 | 中文账号、项目、交接、诊断、用量设置、备份、更新区 | 浏览器测试使用显式夹具，原生弹窗/终端仍需实机验收 |
| 自动升级与回滚 | GUI 开启时检查/下载、Ed25519+SHA256验证、空闲安装、辅助进程、就绪确认、自动/手动回滚、中断恢复 | 可写安装目录；保留上一版；不是操作系统常驻服务 |
| Windows 安装与卸载 | 用户级 setup.exe、两份程序、快捷方式、卸载入口、锁检查与失败恢复 | 卸载保留账号数据；真实安装生命周期在托管 Windows CI 验证 |
| macOS 分发 | Intel/Apple Silicon 原生构建与 DMG；更新包只覆盖自身 .app | 父目录需要可写；系统签名/公证独立可选 |
| CLI 发行 | 三个系统 × amd64/arm64，主命令 cc-router；ccr 仅显式选择的兼容别名 | CachyOS 实机 Bash/Zsh/Fish、macOS Keychain仍需用户设备验收 |

自动化验证包括核心/服务/前端测试、真实辅助进程升级回滚、浏览器交互、三系统 CI、Windows 安装器生命周期与 macOS DMG 挂载检查。每个发行版的实际结果及链接写在发行说明中；CI 通过不等于所有实机和真实账号场景已通过。

系统签名缺失不阻止 GitHub Releases、安装包和 OTA 发布。未签名安装包可能受到系统提示；更新清单签名与操作系统签名是两项独立机制。Gateway、自动换号重放、共享凭据、云同步、中英文切换以及常驻系统服务没有加入本轮范围。
