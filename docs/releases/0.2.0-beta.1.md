# CC Router 0.2.0-beta.1

本版补齐手动额度、本地限额记录、配置备份恢复和桌面安装包，继续提供账号管理、官方登录引导、项目绑定、交接切换及后台更新回滚。版本仍为 **Beta**：模块实现与真实账号、真实终端验收分别记录，不宣称已完成所有实机验收。

**本版本仅从该提交 CI 全部成功的产物发布，并须完成产物核对和 OTA 签名验证。** 实际提交、CI 与校验结果见 [0.2.0-beta.1 发布页](https://github.com/harveyxiacn/cc-router/releases/tag/v0.2.0-beta.1)，构建项目见 [CI workflow](https://github.com/harveyxiacn/cc-router/actions/workflows/ci.yml)。旧 Alpha 的测试结果不作为本版发布证明。

## 下载与安装

| 平台 | 首次安装 | 便携包 / OTA 载荷 |
| --- | --- | --- |
| Windows x64 | `cc-router-desktop-windows-amd64-setup.exe` | `cc-router-desktop-windows-amd64.zip` |
| Linux x64 | 解压右侧便携包 | `cc-router-desktop-linux-amd64.tar.gz` |
| macOS 13+ Apple Silicon | `cc-router-desktop-darwin-arm64.dmg` | `cc-router-desktop-darwin-arm64.tar.gz` |
| macOS 13+ Intel | `cc-router-desktop-darwin-amd64.dmg` | `cc-router-desktop-darwin-amd64.tar.gz` |

Windows 安装到当前用户目录，提供快捷方式和卸载入口，不修改 PATH。macOS 打开匹配 CPU 的 DMG，将应用拖入 Applications；后台更新需要应用及父目录可写，权限不足时请手动替换，或使用自己拥有的便携目录。卸载不删除账号配置、官方 profile、手动记录或配置备份。

EXE 和 DMG 用于首次安装，后台更新下载 ZIP/tar.gz，校验固定发布密钥的 Ed25519 签名、大小和 SHA-256。macOS OTA 归档只包含应用 bundle，不向共享 Applications 目录写入通用 README 或许可证。详见[安装说明](../distribution.md)及[更新与回滚边界](../updates.md)。

本版 **没有 Windows Authenticode、macOS Developer ID 签名或 Apple 公证**。系统可能显示未知发布者或阻止启动；系统证书签名属于可选后续工作，与已实现的 OTA manifest 签名不同。

## 模块补全

- 主命令统一为 `cc-router`。CLI 独立包覆盖三系统的 amd64/arm64，默认不安装可能冲突的 `ccr` 兼容别名；桌面使用随包提供的 CLI，无需配置 PATH。
- 创建账号默认打开官方 CLI 登录流程，由官方 CLI 处理网页登录。可取消自动登录，导入账号不会触发登录；账号已创建而登录启动失败时保留账号并显示错误。
- CLI 和 GUI 可手动记录 5 小时 / 7 天使用百分比、重置时间及本地限额截止时间，明确显示手动来源、记录时间和过期状态，官方状态栏数据保持独立。官方报告达到 95% 时建议审阅交接并手动切换，不推算缺失额度；手动记录不会自动轮换账号或自动阻断会话。
- 本地备份保留稳定账号 ID、默认账号及项目绑定；恢复前预览并确认，支持注册表损坏后的恢复入口。恢复前和更新前自动保存保护备份；活动会话会阻止冲突操作。备份不读取、复制或恢复官方凭据及聊天历史，便携标签导入导出仍为独立功能。
- GUI 提供账号、项目、手动额度、备份、交接、诊断及更新管理。后台检查和下载更新，在无草稿、弹窗、忙碌操作且空闲时应用；保留启动确认、失败回滚、手动回滚及未完成更新恢复。

## 验证与边界

本地 **27 个前端测试通过**，TypeScript/Vite 构建通过。浏览器测试使用明确的测试桥接，覆盖创建后的登录请求、手动/官方额度分离、备份创建和预览确认恢复、交接冲突与更新控件；不使用生产模拟数据。临时目录 Go 测试覆盖配置恢复及数据保留；编译后 CLI 的手动记录、备份、重命名、审阅恢复和清除回路通过，未执行账号登录。

发布门槛包含三系统核心检查、六个 CLI 构建、四个桌面构建、Windows 安装/重装/卸载检查及 macOS DMG 检查；实际结果以本版发布页关联的 CI 为准。

尚需用户在真实环境验收双账号官方登录与重启后的身份隔离、macOS Keychain 隔离、实际终端 Ctrl+C/尺寸变化/交互提示、真实额度上报后的交接，以及真实发布版本间的升级回滚。CachyOS 原生 shell 尚未验收；跨账号共享聊天历史或 `--resume` 不提供保证。没有人为创建新 schema，现有 v1 数据保持兼容，未知 schema 仍严格拒绝。

完整记录见[兼容性与验收表](../compatibility.md)。
