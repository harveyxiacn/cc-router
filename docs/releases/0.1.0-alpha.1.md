# CC Router 0.1.0-alpha.1

本地 Claude Code 多账号工作台的首个预览版，保留独立 CLI。

- 中文桌面 GUI：账号、项目绑定、工作交接、环境诊断和元数据导入/导出。
- 新建账号默认打开官方 CLI 登录流程，由官方客户端引导浏览器认证。
- 官方状态栏的 5h/7d 用量快照：90% 准备交接，任一窗口 95% 提醒手动切换。
- 独立官方配置目录；跨账号通过审阅后的交接文件和实际工作区继续任务。
- 后台下载签名更新，空闲时安装 GUI 和配套 CLI；启动失败自动恢复上一版，支持手动回滚。

桌面包名称以 `cc-router-desktop-` 开头，独立 CLI 包以 `cc-router-` 开头。
下载与你的平台和架构匹配的压缩包，核对 `SHA256SUMS`，解压到固定的可写目录。
Windows/Linux 请保持桌面程序与配套 CLI 在一起；macOS CLI 在 `.app` 内。
使用前需要官方 Claude Code >=2.1.268。

`cc-router-update.json` 和 `cc-router-update.sig` 供内置更新器认证后续发行包。
本版尚未提供 Windows Authenticode 或 macOS 签名/公证。三平台自动化检查、
浏览器测试夹具与辅助进程回滚测试不能代替真实账号、系统终端和真机升级验收。
请先在可恢复的测试项目中试用。详情见仓库中的兼容性、安全和更新说明。

项目独立实现，与 Anthropic 无隶属关系；不读取 token、不复制凭据或跨账号会话历史。
