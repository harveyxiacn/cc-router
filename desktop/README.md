# CC Router 桌面工作台

Wails v2.16 + React + TypeScript 原生桌面界面。账号登记、项目绑定、交接与
诊断直接使用根模块 `internal/desktop`，没有演示账号或前端模拟后端。

账号卡片显示官方状态栏最近上报的 5 小时与 7 天使用比例。没有上报时显示未知；
上报超过 15 分钟或窗口已到期时标记过期，不会推断剩余额度。每 5 秒只读取本地
快照；身份查询和诊断需要点击触发。90% 提醒准备交接，95% 建议手动切换。

添加账号时默认勾选“创建后打开官方登录”，也可以取消。创建成功后打开官方登录
终端，由官方 CLI 完成浏览器授权；无需先选择项目。终端启动失败时账号仍会保留，
点击卡片“登录”即可重试。导入元数据不会自动发起登录。

登录和工作会话由系统终端中的官方 CLI 完成。切换会创建新会话，先保存交接文件、
确认审阅，再启动目标账号。保存冲突会保留草稿，切换前会再次核对文件摘要。
正在使用的账号不会开放重命名或移除操作。

元数据导入导出使用原生文件对话框，大小上限 1 MiB。导出只包含名称、标签与
默认选择，不含凭据、会话历史或项目路径；不会写入应用配置目录。导入按名称
合并并保持原有账号身份，新增账号需要在当前设备重新登录。

账号的“更多操作”提供手动额度与本地限额记录：5 小时、7 天窗口可分别填写已用
百分比和重置时间，也可只标记限额截止时间。时间采用设备本地时区，须在未来一年内。
手动记录与官方上报分开展示，标明来源和记录时间；到期显示失效，不会自动切换账号。
清除操作需要单独确认，保留官方状态栏记录。

“环境诊断”中的本地配置备份保存账号登记（含稳定 ID）、默认选择及本地项目绑定。
恢复前会展示备份内容并要求确认；未保存交接草稿会阻止恢复。当前登记文件损坏时，
仍可通过错误提示进入备份管理。损坏或仅供取证的备份不可恢复；有效恢复前会保存当前
配置，以便再次审阅并撤销。备份不包含官方配置、凭据、聊天历史或交接内容，也不替代
跨设备的元数据导入／导出。手动记录弹窗、备份预览和正在执行的操作都会阻止更新重启。

## 本机构建

“环境诊断”中的“更新与关于”显示当前版本、公开发行说明和固定的官方发行页。后台自动更新默认启用，
可随时关闭。桌面后端在启动与每 6 小时检查一次 GitHub 发行版本；稳定版本只接收稳定通道，
预发行版本可接收预发行通道。发行清单必须通过内置 Ed25519 公钥验证，下载还会验证大小与 SHA-256。
下载和检查不会查询 Claude 身份或使用额度。

自动安装等待交接草稿已保存、弹窗已关闭、没有忙碌操作与受管会话，并要求 30 秒没有键盘或鼠标操作。
“现在重启更新”允许明确选择立即重启；存在草稿或弹窗时仍不可用。重启期间暂停界面操作。
新版本必须打开可用界面并通过健康确认，否则恢复上一版本；也可明确选择回退。
更新支持可写的便携桌面安装，CLI 必须与桌面安装一起放置。开发构建或不可写安装可通过官方发行页手动更新。
安装仅替换软件发行包列出的文件，保留不再列出的旧资源；当前 macOS 包未进行系统代码签名，
后续采用签名应用包时需要整体替换 bundle。日志与回退用于进程中断恢复，不承诺所有断电场景下的持久性。

先安装 Go 1.26+、Node.js 24 LTS 与 npm，再安装固定版本 Wails CLI：

```sh
go install github.com/wailsapp/wails/v2/cmd/wails@v2.16.0
```

平台依赖按 [Wails 官方安装说明](https://wails.io/docs/gettingstarted/installation/)：

- Windows 10/11：WebView2 Runtime；此项目的 Windows 构建无需额外 GCC。
- macOS：Xcode Command Line Tools，在目标 Mac 上原生构建。
- Linux：GCC、GTK3、WebKitGTK 开发包；使用 WebKitGTK 4.1 时添加
  `-tags webkit2_41`。在目标 Linux 上原生构建。

从仓库根目录构建配套 CLI，然后构建桌面应用：

```sh
go build -o cc-router ./cmd/ccr
cd desktop
wails build
```

Windows CLI 的输出文件名应为 `cc-router.exe`。桌面产物位于
`desktop/build/bin/`，文件名前缀为 `cc-router-desktop`；macOS 为 `.app`。
将 CLI 放在桌面可执行文件旁边。macOS 可放在应用包的 `Contents/MacOS` 内，
或放在 `.app` 同级目录。也可以通过 `CC_ROUTER_CLI` 指定 CLI 的绝对路径。
账号数据目录继续使用 CLI 的 `CCR_HOME` 规则。

CLI 主命令为 `cc-router`，桌面运行不要求把程序目录加入 PATH。`ccr` 仅是
可选兼容别名，可能与 musistudio/claude-code-router 的同名命令冲突，不推荐安装或使用。

开发时可运行 `wails dev`。单独运行 `npm run dev` 只提供浏览器视觉预览，
没有 Wails 桥接时会明确显示未连接，不会提供模拟数据。

## 验证

```sh
cd desktop/frontend
npm ci
npm test
npm run build
cd ..
go test ./...
go vet ./...
```

前端单测验证额度未知、过期、阈值、表单输入与交接审阅门槛；Go 测试验证初始化
错误、CLI 路径、原子导出及受保护的文件目标。Windows 无符号链接权限时相关
链接测试会跳过。原生 GUI、文件对话框与终端启动还需在目标系统验证。

桌面模块包含 Wails 和前端第三方依赖，独立于仅使用标准库的核心 CLI。
平台管理策略检测与启动检查的限制见仓库根 README；诊断不代表整个会话期间
的身份保证。账号身份、计费和即时额度仍以官方 `/status`、`/usage` 为准。
